Asociación de CSS a HTML

Esta página muestra las tres formas de usar CSS.

1. CSS en línea (Inline)

El encabezado de arriba tiene el estilo escrito con el atributo style.

2. CSS interno (Internal)

Los encabezados h1, h2 y h3 tienen reglas dentro de la etiqueta style en el head (cambian el tipo de letra).

Este es un h3 con CSS interno y externo

3. CSS externo (External)

Los colores, fondos, bordes y esquinas redondeadas vienen del archivo style.css.

Bordes redondeados
